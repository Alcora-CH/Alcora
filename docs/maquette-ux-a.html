    L'application interroge ton contrôleur pour découvrir les caméras. Rien n'est envoyé ailleurs.

    Mode démonstration : aucune connexion réelle n'est établie.

    Contrôleur

    L'adresse IP de ton UDM, Cloud Key ou UNVR.

    Compte

    Utilise un compte dédié à cette application, avec des droits limités.

    Où trouver cette clé ?

    Sur le site de gestion de ton compte Ubiquiti, lors de l'ajout d'une application d'authentification, choisis « saisie manuelle » plutôt que de scanner le code : la clé s'affiche alors en toutes lettres.

    Garde cette même clé enrôlée sur ton téléphone. Si cette application en devenait l'unique détentrice, perdre ce PC te bloquerait l'accès à ton compte.

    Vérification C'est plus long que prévu…

    • Lire les caméras

      2 flux sur 3 ; Portail n'a pas de RTSP.

    Rester connecté

    Pour se reconnecter seule après un redémarrage, l'application conserve sur ce PC ton mot de passe et la clé qui produit les codes à usage unique, chiffrés par Windows pour ton compte Windows uniquement.

    Concrètement : une personne qui ouvrirait une session sous ton compte Windows pourrait se connecter au contrôleur sans avoir ton téléphone. En revanche, ton compte reste protégé face à quelqu'un qui ne connaîtrait que ton mot de passe.
